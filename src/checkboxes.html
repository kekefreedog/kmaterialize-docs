Basic example

Use checkboxes for independent choices. Wrap the input and its text in a label so clicking either toggles the choice.

<form action="#">
  <p>
    <label>
      <input type="checkbox" />
      <span>Red</span>
    </label>
  </p>
  <p>
    <label>
      <input type="checkbox" checked="checked" />
      <span>Yellow</span>
    </label>
  </p>
  <p>
    <label>
      <input type="checkbox" class="filled-in" checked="checked" />
      <span>Filled in</span>
    </label>
  </p>
  <p>
    <label>
      <input id="indeterminate-checkbox" type="checkbox" />
      <span>Indeterminate Style</span>
    </label>
  </p>
  <p>
    <label>
      <input type="checkbox" checked="checked" disabled="disabled" />
      <span>Green</span>
    </label>
  </p>
  <p>
    <label>
      <input type="checkbox" disabled="disabled" />
      <span>Brown</span>
    </label>
  </p>
</form>

Setup

{{> input-native-setup }}

Wrap each checkbox and its text in a <label>, with the text in a <span>. No JavaScript initialization is required. Set the native indeterminate property for a partially selected group.

document.querySelector('#indeterminate-checkbox').indeterminate = true;

Validation

A required checkbox must be checked. For rules such as “select at least two,” validate the whole group in your application and associate one message with the group.

Keyboard and accessibility

Use Tab to focus a checkbox and Space to toggle it. Give each choice a visible label. Group related choices with a <fieldset> and <legend>. An indeterminate checkbox still submits according to its checked state.
