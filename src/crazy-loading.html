Setup and API

Load Materialize CSS and import CrazyLoading from kmaterialize. Both tags register automatically. The component extends Kmcomponent and initializes the library’s Loading internally. Its internal indicator opts out of AutoInit and releases its Loading instance when updated or disconnected.

import { CrazyLoading } from 'kmaterialize';

const loading = document.querySelector<CrazyLoading>('crazy-loading')!;
loading.start('Refreshing assets…');
await loading.updateComplete;
console.log(loading.isActive); // true

// When the operation finishes:
loading.stop('Assets ready');
await loading.updateComplete;

// Attributes and typed properties are reactive too:
loading.setAttribute('image', '/images/project-logo.svg');
loading.setProperty('size', 'small');
loading.setProperty('active', false);
AttributeValues / default
activetrue by default. Use active="false" or "0" to stop; presence, "true", or "1" starts. Removing the attribute restores the default.
sizesmall (4rem), normal (7rem, default), large (10rem). The legacy alias defaults to large.
label / complete-labelLoading… / Ready. Accessible status while active / finished.
aria-labelOptional override for the active status label; omit when using start(label).
imageLogo URL, empty by default. Takes precedence over icon-text. Images are decorative; label describes the status.
icon-text / icon-classIcon text, empty by default / material-icons. Load the corresponding icon font in your application.
hiddenNative hidden attribute hides the whole component without changing its active state.
CSS propertyDefault
--loading-size7rem, or the chosen size
--loading-colorEnvironment primary color (ring and icon)
--loading-backgroundEnvironment surface container, falling back to surface
--loading-thickness3px

start(label?), stop(label?), and isActive mirror Loading. Attribute/property changes render in a microtask; await updateComplete before inspecting the DOM. Supplied start/stop labels remain in their respective properties for later calls. The runtime cleans up automatically; remove the element when its view is no longer needed.

The indicator exposes a polite status and aria-busy. Decorative content is hidden from assistive technology. Reduced-motion preferences keep the ring visible without rotation. Use a separate button for actions. The old fixed purple ring and light/dark palette are replaced by environment colors; existing legacy container/logo class hooks are retained.
