In material design, everything should have a certain z-depth that determines how far raised or close to the page the element is.

You can easily apply this shadow effect by adding a class="z-depth-2" to an HTML tag. Alternatively you can extend any of these shadows with Sass using @extend .z-depth-2. A z-depth-0 can be used to remove shadows from elements that have z-depths by default.

Gradient Shadows

Every gradient also comes with its own tinted drop shadow - a box-shadow colored to match the gradient's end color, instead of a flat grey. Two ways to use it:

Combined with the gradient

Add gradient-shadow alongside the matching gradient-45deg-* background class.

Copied!content_copy
<div class="gradient-45deg-purple-pink gradient-shadow" style="height: 70px;"></div>
Standalone

gradient-45deg-<start>-<end>-shadow applies the same tinted shadow on its own, without needing the gradient background class too - handy for a plain card-panel or button that should just glow like a gradient without actually being one.
