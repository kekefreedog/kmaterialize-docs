Basic example

ColorInput enhances a native <input type="color"> with a full Pickr popup - palette, hue/opacity sliders, swatches, hex/rgba/hsla. Opt in by adding data-color-picker="pickr": without it the input stays a plain native color swatch, completely unaffected. 

<div class="input-field">
  <input id="color-example-1" type="color" data-color-picker="pickr" data-color-theme="nano" value="#26a69a">
  <label for="color-example-1">Accent color</label>
</div>

Setup

{{> input-setup-note }}

Pickr is an optional peer dependency, loaded on demand only when a data-color-picker="pickr" input is actually initialized - install it yourself: npm install @simonwep/pickr. 

import '@simonwep/pickr/dist/themes/nano.min.css';
import 'kmaterialize/dist/css/materialize.css';

Each opted-in input needs to resolve Pickr asynchronously before the popup exists - await instance.ready if you need to interact with it right after init. 


  document.addEventListener('DOMContentLoaded', function() {
    const elems = document.querySelectorAll('input[type="color"][data-color-picker="pickr"]');
    const instances = ColorInput.init(elems, {
      // specify options here
    });
  });

Validation

A native color input always has a color value; required and maxlength do not apply. Show a message for application rules, such as an unavailable brand color.

{{> validation-note }}
Unsupported color

error Choose a color from your approved brand palette.

</div>
<p id="validation-color-error" class="supporting-text error-text"><i class="material-icons" aria-hidden="true">error</i> Choose a color from your approved brand palette.</p>

Reference

Options

Name Type Default Description
theme String 'classic' Pickr theme: 'classic', 'monolith' or 'nano'. Overridable per-input via data-color-theme.
opacity Boolean true Whether the opacity slider is shown. Locked via data-color-opacity="false".
swatches Array 14 preset colors Swatch palette shown in the popup.
locale Object undefined Pickr i18n string overrides. A built-in French translation is used automatically for data-color-locale="fr-fr" if this isn't passed.

Methods

All the methods are called on the plugin instance. You can get the plugin instance like this:


                  const instance = ColorInput.getInstance(elem);
.destroy();

Destroy plugin instance, removes the Pickr popup and un-hides the native input.


instance.destroy();

Properties

Name Type Description
el Element The native <input type="color"> the plugin was initialized with.
ready Promise<void> Resolves once Pickr has loaded and the popup has been created.
pickr Pickr The underlying Pickr instance, once ready resolves.
