FileInput enhances the existing .file-field structure in place with a FilePond drag-and-drop uploader - add data-file-picker="filepond" to an otherwise completely stock .file-field, nothing else about the markup changes. FilePond hides the native <input type="file"> and injects its own root as a sibling, so the surrounding button/label/file-path-wrapper stay intact at rest.

FilePond is an optional peer dependency, loaded on demand - install it yourself (npm install filepond) and import its base stylesheet once. The image-preview plugin also requires its own stylesheet. Optional plugins (image-preview, file-validate-type, image-exif-orientation) are each their own optional peer, listed via data-file-plugins="image-preview,file-validate-type". 

Copied!content_copy
import 'filepond/dist/filepond.min.css';
import 'filepond-plugin-image-preview/dist/filepond-plugin-image-preview.min.css';
File 
Copied!content_copy
<div class="file-field input-field" data-file-picker="filepond" data-file-plugins="image-preview,file-validate-type">
  <div class="btn">
    <span>File</span>
    <input type="file" accept="image/*">
  </div>
  <div class="file-path-wrapper">
    <input class="file-path validate" type="text" placeholder="Upload one or more files">
  </div>
</div>

Initialization

this.el is the .file-field container itself, not the file input.

Copied!content_copy
  document.addEventListener('DOMContentLoaded', function() {
    const elems = document.querySelectorAll('.file-field[data-file-picker="filepond"]');
    const instances = FileInput.init(elems, {
      // specify options here
    });
  });

Options

Name Type Default Description
plugins Array [] Which FilePond plugins to register: any of 'image-preview', 'file-validate-type', 'image-exif-orientation'. Derived from data-file-plugins if not passed. file-validate-type is auto-registered whenever the input restricts accept, even if not listed.
Input attributes HTML attributes - Supports multiple, accept, disabled, data-default-file, data-max-files, data-allow-reorder, data-label-idle, data-instant-upload, data-drop-validation, data-image-preview-height, data-style-panel-layout, and data-style-panel-aspect-ratio. Use data-file-height to give compact layouts an explicit pixel height.

Methods

All the methods are called on the plugin instance. You can get the plugin instance like this:

Copied!content_copy
                  const instance = FileInput.getInstance(elem);
.getFiles();

Convenience wrapper over the underlying FilePond instance's own getFiles().

Return Value

Array: The FilePond file items currently loaded.

Copied!content_copy
instance.getFiles();
.destroy();

Destroy plugin instance and teardown the FilePond widget.

Copied!content_copy
instance.destroy();

Properties

Name Type Description
el Element The .file-field container the plugin was initialized with.
ready Promise<void> Resolves once FilePond (and its plugins) have loaded and the widget has been created.
pond FilePond The underlying FilePond instance, once ready resolves.
