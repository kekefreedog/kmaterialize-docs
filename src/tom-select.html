Basic example

TomSelectField enhances an EXISTING native <select> with Tom Select - searchable, taggable, remote-loading, dependent-field wiring, a clear button, drag-drop reorder. Opt in with the tomselected class. 

<div class="input-field">
  <select id="tomselect-example-1" class="tomselected" data-select-clear="" placeholder="Choose your option">
    <option value="" disabled selected></option>
    <option value="1">Option 1</option>
    <option value="2">Option 2</option>
    <option value="3">Option 3</option>
  </select>
  <label for="tomselect-example-1">Searchable select</label>
</div>

<div class="input-field">
  <select id="tomselect-example-2" class="tomselected" data-select-tag="" multiple>
    <option value="1">Option 1</option>
    <option value="2">Option 2</option>
    <option value="3">Option 3</option>
  </select>
  <label for="tomselect-example-2">Taggable multi-select</label>
</div>

Setup

{{> input-setup-note }}

Tom Select is an optional peer dependency, loaded on demand - install it yourself: npm install tom-select. 

import 'tom-select/dist/css/tom-select.css';
import 'kmaterialize/dist/css/materialize.css';

If you also call FormSelect.init(...) yourself elsewhere (rather than relying on AutoInit()), exclude .tomselected from that call too, so a select is never initialized by both components. 


  document.addEventListener('DOMContentLoaded', function() {
    FormSelect.init(document.querySelectorAll('select:not(.tomselected)'), {});
    TomSelectField.init(document.querySelectorAll('select.tomselected'), {
      // specify options here
    });
  });

Coexistence with FormSelect: a .tomselected select is never picked up by FormSelect's own AutoInit selector - it's excluded the same way .no-autoinit is. If you initialize both manually (as this docs site does, since it never calls the global AutoInit()), make sure your own FormSelect.init(...) call also excludes .tomselected.

Validation

Keep constraints on the original select and connect its error message with aria-describedby. Your application should also update the generated control’s accessible error state when applying validation after initialization.

{{> validation-note }}
Required searchable selection
error Choose a department. 
<div class="input-field outlined error">
    <select id="validation-tom-select" name="department" class="tomselected" required aria-invalid="true" aria-describedby="validation-tom-select-error">
        <option value="" selected disabled></option>
        <option value="design">Design</option>
        <option value="production">Production</option>
    </select>
    <label for="validation-tom-select">Department</label>
    <span id="validation-tom-select-error" class="supporting-text"><i class="material-icons" aria-hidden="true">error</i> Choose a department.</span>
</div>

Reference

Options

Name Type Default Description
remote Object undefined { url, value, label, search, dataKey } - fetches options remotely. Derived from data-select-remote (JSON) if not passed. label may be a {{field}} render template.
settings Object undefined Raw Tom Select settings, merged in last - escape hatch for anything not covered by the dataset attributes below.

Per-select attributes, matching the CrazyPHP convention this component was ported from:

Attribute Description
data-select-tag Allows creating new options (tagging); also enables the drag-drop reorder plugin.
data-select-clear Adds a clear button, with this attribute's value as its title.
data-select-remote JSON-encoded { url, value, label, search, dataKey } remote data spec.
data-depends A selector for another element; this select's remote options reload when it changes.

Methods

All the methods are called on the plugin instance. You can get the plugin instance like this:


                  const instance = TomSelectField.getInstance(elem);
.destroy();

Destroy plugin instance and teardown the Tom Select widget.


instance.destroy();

Properties

Name Type Description
el Element The native <select> the plugin was initialized with.
ready Promise<void> Resolves once Tom Select has loaded and the widget has been created.
tomSelect TomSelect The underlying Tom Select instance, once ready resolves.
