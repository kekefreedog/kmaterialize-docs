Sticky and fixed footer

Keep useful actions at the bottom of the viewport with footer-layout footer-fixed. The main area scrolls, and the footer reserves its actual height so it never covers the last line of content. Remove footer-fixed for a sticky footer that follows long content.

Use the Crazy Button controls to switch modes and add content. You can also open the full-page example. This demonstrates the sticky and fixed modes named in the reference pen.

Copied!content_copy<body class="footer-layout footer-fixed">
  <header>Site navigation</header>
  <main>
    <!-- Your page content scrolls here. -->
  </main>
  <footer class="page-footer footer-bordered surface-variant px-4 pt-0">
    <div class="footer-copyright screen-flex screen-wrap">
      <span>© 2026 Your team</span>
      <crazy-button type="extended" variant="filled" size="normal"
          label="Get started" href="getting-started.html"></crazy-button>
    </div>
  </footer>
</body>

Both layout classes belong on the page wrapper or body, with header, main, and footer as direct children. The default height is the viewport; set --footer-layout-height for an embedded layout. No JavaScript is needed for positioning. Load kmaterialize JavaScript to register crazy-button.

Choosing a footer

Use a multi-column footer for several navigation groups, a compact footer for a small application, or a centered footer for a short closing message. Keep link labels descriptive and give each navigation group an accessible label.

The footer layouts use kmaterialize classes and need no initialization. Add footer-bordered for the visible outline shown in these examples. Load kmaterialize JavaScript to register crazy-button for the call-to-action example. mt-0 removes the default space above a footer; padding utilities control its inner spacing. Pair background and text colors, such as primary-container on-primary-container-text, and resize the page or switch themes to preview each layout.
