More ways to build with Materialize

Kmaterialize builds on the familiar Materialize foundation with additional components, richer variants, and integrations for application interfaces. Explore the shared foundations, then try the features documented here.

Original Materialize

The original library brings Material Design to the web through a responsive grid, forms, cards, navigation, and interactive components.

Explore materializecss.com

Materialize Web

The community continuation develops the shared component foundation with vanilla JavaScript, TypeScript, and Material Design guidance.

Explore materializeweb.com

Kmaterialize

This project extends that foundation with workflow components, expanded control examples, themed integrations, and practical customization guides.
