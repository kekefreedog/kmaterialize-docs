Card Badges

Use badges on image cards to highlight a status, recommendation, or availability.

Place a card-badges group inside card-image to display custom labels above the image. Badges sit in the top-right corner by default; add left to move the group to the top-left. Multiple badges wrap when space is limited.

Featured New

Combine custom labels and colors without changing the card layout.

Weekend adventure
starRecommended 3

Use icons and the existing data-badge-caption attribute for extra context.

<div class="card">
  <div class="card-image">
    <img src="images/sample-1.jpg" alt="Mountain lake surrounded by trees">
    <span class="card-title gradient">Lakeside escape</span>
    <div class="card-badges">
      <span class="badge">Featured</span>
      <span class="badge" style="--card-badge-background: var(--md-sys-color-tertiary-container); --card-badge-color: var(--md-sys-color-on-tertiary-container);">New</span>
    </div>
  </div>
  <div class="card-content"><p>Discover your next destination.</p></div>
</div>

Set --card-badge-background and --card-badge-color on a badge, group, or card to customize its colors. Use paired theme tokens so they adapt to light and dark mode. The badges also work with small, medium, and large image cards.

Labels allow clicks through to the image. For an interactive badge, use <a class="badge" href="…">Featured</a> with a descriptive label. No JavaScript is required.

Badges with Icons

Place an icon before the label inside a badge. Kmaterialize centers the icon and text, with consistent sizing for Material Icons and Font Awesome. This works with standard badges and card-overlay badges.

Load the stylesheet for your chosen icon set in the page's <head>, alongside Kmaterialize:

<!-- Material Icons -->
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons">
<!-- Font Awesome Free -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css">

Standard badges

Use data-badge-caption="" when your label replaces the default “new” caption. No additional icon alignment classes are needed.

lockProject ManagerMaterial Icons
Project ManagerFont Awesome
<!-- Material Icons -->
<span class="new badge" data-badge-caption=""><i class="material-icons" aria-hidden="true">lock</i>Project Manager</span>
<!-- Font Awesome -->
<span class="new badge" data-badge-caption=""><i class="fa-solid fa-lock" aria-hidden="true"></i>Project Manager</span>
