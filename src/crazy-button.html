Navigation rail

Use type="rail" for an icon above a visible label, matching the navigation rail example. The inner link receives href, data-view, and aria-current. The active icon pill follows the environment’s secondary container colors.

Choose a section to update its current-page indicator.

Copied!content_copy<crazy-button type="rail" href="#rail-home" data-view="Home" icon-text="home" label="Home" aria-current="page"></crazy-button>
<crazy-button type="rail" href="#develop" data-view="Develop" icon-text="code" label="Develop"></crazy-button>
<crazy-button type="rail" href="#rail-settings" data-view="Settings" icon-text="settings" label="Settings" disabled></crazy-button>

Set aria-current="page" on the component for the current destination and remove it from the others when your route changes. Rail geometry is fixed at 88px wide and at least 76px high; the other button size, shape, variant, and wave options apply to the other types.

Setup and API

Load Materialize CSS and an icon font, then import CrazyButton from kmaterialize. Both custom element names register automatically in the browser. For labeled icon buttons, install the optional tippy.js peer and load its styles as shown on the Tooltips page. Do not also initialize these controls with initMaterialButtons.

import { CrazyButton, Kmcomponent } from 'kmaterialize';


const button = document.querySelector<CrazyButton>('crazy-button')!;
button.setProperty('label', 'Ready');
button.setAttribute('variant', 'filled');
await button.updateComplete;
button.addEventListener('buttonaction', (event) => {
  console.log((event as CustomEvent).detail); // { action, pressed }
});

Kmcomponent is the CrazyPHP Crazycomponent2 script renamed, including its property schema, typed conversion, batched rendering, light DOM projection, optional shadow root, setHtmlAndCss, postRender, and onCleanup APIs. Crazy button uses light DOM for the host environment's styles.

AttributeValues / default
typefloating (default), extended, icon, fab, extended-fab, rail
depthflat (default), outlined, 1–5; variant takes precedence over the legacy style
shape / sizeround (default), box, square / large (default), small, normal, extra-large, xs, sm, md, lg, xl
wavelight (default), dark, false
tooltip-styleclassic (default), material. Uses the optional tippy.js peer; load its styles before Materialize CSS.
tooltip-positiontop (default), right, bottom, left. Tooltip placement for floating, icon, and FAB buttons.
label / icon-text / icon-classEmpty label and icon; icon-class defaults to material-icons
icon-image / icon-image-style / icon-positionImage URL / inline image CSS / right (default), left
color-primary / color-secondaryBackground / foreground and outline. CSS colors, var(...) expressions, or legacy palette classes such as blue lighten-5. Class colors require the legacy Materialize colors stylesheet.
data-view / aria-currentNavigation view identifier / current destination (for example page). Forwarded reactively to the inner control.
href / targetEmpty (native button) / _self (default), _blank. Links use anchors; disabled links become disabled buttons.
variantfilled, tonal, outlined, elevated, text, standard (unfilled icon); omitted: derive from depth
toggle / pressed / disabled / splitBoolean: presence, true, or 1 enables; false or 0 disables; omitted defaults to false
icon-widthnormal (default), narrow, wide
fab-color / fab-sizeprimary (default), secondary, tertiary / normal (default), small, large
menu-target / menu-labelExternal dropdown element ID / More options (default)
aria-label / actionAccessible name override / buttonaction event identifier (defaults to label)
button-type / name / value / formbutton (default), submit, reset / native form button attributes

Migration notes: regular-btn is registered only when that tag is free; load this implementation instead of the old registration. Existing attribute names and floating/extended behavior are retained. Default colors now inherit the environment instead of forcing blue lighten-5. Raw HTML in the old label attribute should be moved into child markup. Use native click listeners for activation or buttonaction for the component's action and selection state (pressed is "true", "false", or null). External dropdown items keep their own handlers.
