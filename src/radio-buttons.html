Basic example

Radio Buttons are used when the user must make only one selection out of a group of items. The for attribute is necessary to bind our custom radio button with the input. Add the input's id as the value of the for attribute of the label.

Add radio buttons to a group by adding the name attribute along with the same corresponding value for each of the radio buttons in the group. Create disabled radio buttons by adding the disabled attribute as shown below. 

<form action="#">
  <p>
    <label>
      <input name="group1" type="radio" checked />
      <span>Red</span>
    </label>
  </p>
  <p>
    <label>
      <input name="group1" type="radio" />
      <span>Yellow</span>
    </label>
  </p>
  <p>
    <label>
      <input class="with-gap" name="group1" type="radio"  />
      <span>Green</span>
    </label>
  </p>
  <p>
    <label>
      <input name="group1" type="radio" disabled="disabled" />
      <span>Brown</span>
    </label>
  </p>
</form>

Setup

{{> input-native-setup }}

Give every radio in a group the same name and a different value. Wrap each radio and its text in a <label>, with the text in a <span>. No JavaScript initialization is required.

Examples and variants

Horizontal

Place radio options side by side with radio-group-horizontal. They wrap onto another line when space is limited. Tab enters the group and arrow keys change the selection, skipping disabled options.

<!-- The shared name keeps this group independent from the other examples. -->
<div class="radio-group-horizontal" role="radiogroup" aria-label="Delivery priority">
  <label>
    <input type="radio" name="horizontal-priority" value="low" checked>
    <span>Low</span>
  </label>
  <label>
    <input type="radio" name="horizontal-priority" value="normal">
    <span>Normal</span>
  </label>
  <label>
    <input type="radio" name="horizontal-priority" value="high">
    <span>High</span>
  </label>
  <label>
    <input type="radio" name="horizontal-priority" value="urgent" disabled>
    <span>Urgent (unavailable)</span>
  </label>
</div>

The radio-group-horizontal layout is included in kmaterialize. No extra CSS or JavaScript initialization is required.

With Gap

To create a radio button with a gap, add class="with-gap" to your input. See the example below. 

<p>
  <label>
    <input class="with-gap" name="group3" type="radio" checked />
    <span>Red</span>
  </label>
</p>

Validation

Give radio buttons the same name. A required group needs one selected option. Use fieldset.radio-group and a legend to label the group and keep its error message beneath the options.

Delivery method

error Choose a delivery method.

<fieldset class="radio-group error" aria-describedby="validation-radio-error">
    <legend>Delivery method</legend>
    <p><label><input type="radio" name="validation-delivery" value="email" required aria-invalid="true" aria-describedby="validation-radio-error"><span>Email</span></label></p>
    <p><label><input type="radio" name="validation-delivery" value="download" required aria-invalid="true" aria-describedby="validation-radio-error"><span>Download</span></label></p>
    <p id="validation-radio-error" class="supporting-text error-text"><i class="material-icons" aria-hidden="true">error</i> Choose a delivery method.</p>
</fieldset>

Keyboard and accessibility

Tab moves into or out of the radio group; arrow keys move between its options. Use a <fieldset class="radio-group"> with a <legend> to name a group, as shown in the validation example.
