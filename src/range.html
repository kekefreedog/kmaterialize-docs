Material range

Choose a value with a mouse, touch, or keyboard. A rounded track shows the selected amount, while the circular thumb and focus ring follow your Material theme.

40 
<div class="range-field">
  <label for="volume">Volume</label>
  <input id="volume" type="range" min="0" max="100" value="40"
         data-value-label="false">
</div>

All slider styling and behavior are included in kmaterialize. Existing input[type="range"] controls receive the new appearance. The native input preserves form submission and keyboard interaction.

Steps and tick marks

Use step for discrete values and data-ticks for visible marks. Focus or drag the slider to reveal its value label.

60 
<div class="range-field">
  <label for="brightness">Brightness</label>
  <input id="brightness" type="range" min="0" max="100"
         step="10" value="60" data-ticks>
</div>

Dense tick sets are thinned to at most 101 marks. step="any" allows continuous values and does not display ticks.

Formatted values

Use formatValue to give the value label and assistive technology a meaningful unit. The underlying form value remains numeric.

3.5k credits 
import { Range } from 'kmaterialize';

const input = document.querySelector<HTMLInputElement>('#range-budget')!;
Range.init(input, {
  formatValue: value => `${value / 1000}k credits`
});

Initialization and updates

Ranges present when kmaterialize loads initialize automatically. For controls added later, call Range.init(input). Reinitialization safely replaces the previous instance.

const slider = Range.init(input, {
  showValue: true, // Default: show a label during interaction.
  showTicks: false
});

input.value = '75';
slider.update(); // Refresh after assigning a value in code.

// When removing the component:
slider.destroy();

The library keeps the track and label synchronized on input, reset, resizing, and changes to min, max, step, or disabled. Arrow keys adjust the value; Home and End reach the limits. Label every slider with a linked label or aria-label.

The outputs in these demos use a standard input listener:

input.addEventListener('input', () => {
  output.value = input.value;
});
