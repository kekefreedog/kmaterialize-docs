Install and initialize
Shared spreadsheet styles are loaded once in src/style.scss. Install with pnpm add kspreadsheet@2.7.0 jsuites@5.13.5. The default grid keeps vendor colors; load spreadsheet_editors.scss after them for Material dropdown menus and readable editing text. For the optional Material variant, import the enhancement styles from kmaterialize/sass/enhancement as shown below. Both stylesheets are shipped by the library.

Material enhancement
The imported styles preserve editor font size and color, raise active dropdown cells above frozen columns, round popup corners, and style worksheet tabs. The companion jSuites enhancement covers dropdowns, calendars, context menus, and color pickers. All enhancement rules are scoped under spreadsheet-material; default grids retain kspreadsheet’s colors. The Material variant follows the site’s light and dark themes.

/// with the Materialize look & feel (https://github.com/materializecss/materialize) so the
/// dropdowns, calendars, context menus and color pickers rendered by kSpreadsheet
/// (https://github.com/kekefreedog/kspreadsheet) read like native Materialize surfaces.
///
/// Two hard conflicts are resolved here:
///   1. Materialize styles every raw `<select>` (width:100%, height:3rem, border) which breaks
///      the inline month / year selectors of the jSuites calendar.

/// properties kSpreadsheet relies on (position, transform, z-index, dimensions) are left

/// by jspreadsheet.css — so kSpreadsheet is never compromised.
