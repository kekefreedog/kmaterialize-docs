Breadcrumbs are a good way to display your current location. This is usually used when you have multiple layers of content.

With Crazy Button

Use Crazy Button links inside each breadcrumb. Medium tertiary FABs show each location as an icon. Labels provide accessible names and tooltips; the last link marks the current page.

Copied!content_copy
<nav class="breadcrumb-wrapper" aria-label="Breadcrumb">
  <div class="s12">
    <span class="breadcrumb">
      <crazy-button type="fab" icon-text="home" label="Home" fab-color="tertiary" fab-size="normal" href="index.html"></crazy-button>
    </span>
    <span class="breadcrumb">
      <crazy-button type="fab" icon-text="widgets" label="Buttons" fab-color="tertiary" fab-size="normal" href="buttons.html"></crazy-button>
    </span>
    <span class="breadcrumb">
      <crazy-button type="fab" icon-text="add" label="Breadcrumbs" fab-color="tertiary" fab-size="normal" href="breadcrumbs.html" aria-current="page"></crazy-button>
    </span>
  </div>
</nav>

Load Materialize CSS and JavaScript to register crazy-button automatically. For icon label tooltips, also install tippy.js and load its styles, as shown on the Tooltips page. No additional initialization is needed.
