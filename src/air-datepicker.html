AirDatepickerField enhances a text input with the air-datepicker calendar/range picker. This is a separate, opt-in component from kmaterialize's own native Datepicker - opt in with data-date-picker="air-datepicker", and add the multiple attribute (or data-date-range="true") to switch it into range-selection mode.

air-datepicker is an optional peer dependency, loaded on demand - install it yourself (npm install air-datepicker) and import its base stylesheet once: 

Copied!content_copy
import 'air-datepicker/air-datepicker.css';

Initialization

Copied!content_copy
  document.addEventListener('DOMContentLoaded', function() {
    const elems = document.querySelectorAll('input[data-date-picker="air-datepicker"]');
    const instances = AirDatepickerField.init(elems, {
      // specify options here
    });
  });

Options

Name Type Default Description
locale Object undefined An air-datepicker locale object, used when the input has data-date-lang="fr-FR" (only "fr-FR" is wired up so far).

Per-input attributes, matching the CrazyPHP convention this component was ported from:

Attribute Description
data-date-format air-datepicker format string, default yyyy-MM-dd.
multiple / data-date-range="true" Switches to range mode, joining the two dates with " - ".
min / max Bound the selectable range.
value Preselects one date, or two dates separated by " - " in range mode.
data-date-timepicker / data-date-time-format Enables time selection and optionally sets its format.
data-date-view / data-date-min-view Uses days, months, or years; set both to months for month-only selection.
data-date-buttons Comma-separated preset buttons: today,clear.
data-date-position Popup position such as right center.
data-date-mobile Set to true to use Air Datepicker's modal-style mobile presentation.
data-date-auto-close Set to false to keep the popup open, useful with action buttons.

Methods

All the methods are called on the plugin instance. You can get the plugin instance like this:

Copied!content_copy
                  const instance = AirDatepickerField.getInstance(elem);
.destroy();

Destroy plugin instance and teardown the calendar popup.

Copied!content_copy
instance.destroy();

Properties

Name Type Description
el Element The text input the plugin was initialized with.
ready Promise<void> Resolves once air-datepicker has loaded and the picker has been created.
picker AirDatepicker The underlying air-datepicker instance, once ready resolves.
