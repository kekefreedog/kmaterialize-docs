Timeline

Show milestones, activity, or a story in chronological order. Cards alternate around a connecting line and become a single column when the timeline has 600px or less of available space.

Use timeline, timeline-event, timeline-content, and timeline-badge. These styles are included in kmaterialize; no JavaScript initialization is required.

Customization

Use paired color utilities on icon markers, such as tertiary on-tertiary-text. Colors follow the current light or dark theme.

CSS variableDefaultPurpose
--timeline-line-colorOutline variantConnecting line color
--timeline-line-width2pxConnecting line thickness
--timeline-badge-size40pxIcon marker size; empty dots remain 16px
--timeline-marker-gap12pxClear space between each marker and the connecting line
--timeline-gap16pxSpace between markers and cards
--timeline-event-spacing12pxSpace above and below each event

Content and accessibility

Keep events in chronological order in the markup. Use an ordered list with an accessible label and time datetime="…" for dates. Decorative markers use aria-hidden="true"; describe the event or status in the card text. The visual alternation does not change reading or keyboard order.
