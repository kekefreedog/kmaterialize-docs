Spacing

These classes help space elements with margin and padding helpers for all directions. This works by combining a margin/padding prefix, a direction infix and value suffix

Prefix margin and padding modifiers
Prefix Modifies
m* Modifies the margin according to the infix and suffix values. If no infix is provided, it will be applied to all directions.
p* Modifies the padding according to the infix and suffix values. If no infix is provided, it will be applied to all directions.
Inffix direction modifiers
Infix Direction
*t Applies modifier to the top side of the element
*r Applies modifier to the right side of the element
*b Applies modifier to the bottom side of the element
*l Applies modifier to the left side of the element
*x Applies modifier to the left and right sides of the element
*y Applies modifier to the top and bottom sides of the element
Suffix values

Any margin or padding modifier must be appended with one of 6 value suffixes

Suffix Value
*-0 0
*-1 0.25rem
*-2 0.5rem
*-3 0.75rem
*-4 1rem
*-5 1.5rem
*-6 3rem

padding-* / margin-* aliases

padding-0 through padding-6 and margin-0 through margin-6 are exact aliases of the all-direction p-*/m-* classes above (same steps, same values) - spelled out in full for projects whose markup already uses that naming. There's no -auto or per-direction (-top, -x, ...) variant under this name; use p-*/m-* and friends for that. 

Copied!content_copy
<div class="padding-2 margin-3">Same as class="p-2 m-3"</div>

Screen Fit

Utility classes to size an element to (or at least to) the full viewport, without writing custom CSS.

Class Effect Description
screen-fit width: 100%; height: 100vh; Locks the element to exactly the viewport's width and height. Content taller than the viewport gets clipped/overflows unless you handle it yourself.
screen-fit-x width: 100%; Full width only - height is left untouched, so the element grows naturally with its content.
screen-fit-y align-items: stretch; Not a size at all - it makes a flex/grid container's children stretch to fill its cross-axis. Use it on the parent, not the item you want stretched.
screen-fit-min min-width: 100%; min-height: 100vh; Fills at least the viewport - unlike plain screen-fit, taller content simply pushes the element taller instead of being clipped.
screen-fit-min-x min-width: 100%; height: 100vh; Width can only grow (min 100%), height is locked exactly to the viewport.
screen-fit-min-y width: 100%; min-height: 100vh; Width is locked to 100%, height can only grow (min 100vh) - the most common one for a "full height, but can scroll if content is long" page wrapper.
screen-fit-y in action

The only one of these that's actually demoable inside a small box: compared here against screen-top-y so the difference is visible. Same markup, same tall chip - screen-top-y leaves the shorter chips at their natural height, screen-fit-y stretches them to match:

tall chip
screen-top-y: not stretched
screen-top-y: not stretched
tall chip
screen-fit-y: stretched
screen-fit-y: stretched
Copied!content_copy
<div class="screen-flex screen-top-y">
  <div class="chip">tall chip</div>
  <div class="chip">screen-top-y: not stretched</div>
</div>

<div class="screen-flex screen-fit-y">
  <div class="chip">tall chip</div>

Typical usage

The rest are viewport-relative by nature (100vh), so they can't be demoed inside a small box on this page without covering it - here's how they're meant to be used instead.

screen-fit: an app shell that never scrolls the outer page, only an inner content area does.

Copied!content_copy
<div class="screen-fit screen-flex screen-direction-y-asc">
  <header>App bar</header>
  <main class="element-flex-grow-1" style="overflow-y: auto;">Scrollable content</main>
  <footer>Status bar</footer>
</div>

screen-fit-min: a landing-page hero that always fills the first screen, but grows if its own text/image needs more room.

Copied!content_copy
<section class="screen-fit-min screen-flex screen-center">
  <h1>Welcome</h1>
</section>

Screen Flex

screen-flex turns an element into a flex container; combine it with any of the modifier classes below on the same element to control alignment, wrapping and direction. element-flex-grow-1, used on a direct child, makes that child grow to fill remaining space.

screen-center: centers children horizontally and vertically at once.

screen-center

Emphasis & standalone flex

screen-flex-important: same as screen-flex, but !important - for when something more specific already set display on the element.

element-flex: a plain display: flex; with none of screen-flex's modifier machinery - for a quick flex container that doesn't need any of the above.

element-flex-grow-1: put on a direct child of a screen-flex container to make just that child grow and fill the remaining space, while its siblings keep their natural size.

fixed

</div>
