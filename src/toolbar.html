A rounded "pill" action bar for grouping controls above the content they act on - buttons, a segmented "track" control (e.g. Today/Previous/Next), and an expandable search field. It's a plain flex row in normal page flow, not fixed or sticky. 

Copied!content_copy
<div class="toolbar">
  <div class="toolbar-group">
    <div class="toolbar-track">
      <div class="toolbar-track-indicator"></div>
      <button class="toolbar-track-item is-active">Today</button>
      <button class="toolbar-track-item">Previous</button>
      <button class="toolbar-track-item">Next</button>
    </div>
  </div>
  <div class="toolbar-group">
    <div class="toolbar-search">
      <button class="toolbar-search-toggle"><i class="material-icons">search</i></button>
      <input class="toolbar-search-input" placeholder="Search...">
    </div>
    <button class="btn-floating btn-small"><i class="material-icons">refresh</i></button>
  </div>
</div>

Groups

toolbar-group clusters related controls (buttons, a track, a search field, ...) with a small gap between them, and a bigger gap between groups themselves - the toolbar lays groups out with justify-content: space-between.

A regular btn fits into a group just as well as a btn-floating:

add remove Reset crop_free
download refresh

Track (segmented control)

A pill-shaped segmented control with a sliding highlight behind whichever toolbar-track-item is is-active. Click an item below - the Toolbar component slides the toolbar-track-indicator to match. 

Copied!content_copy
<div class="toolbar-track">
  <div class="toolbar-track-indicator"></div>
  <button class="toolbar-track-item">Week</button>
  <button class="toolbar-track-item is-active">Month</button>
  <button class="toolbar-track-item">6 Month</button>
  <button class="toolbar-track-item">Year</button>
</div>

Add toolbar-track-bare for a track with no background/border of its own - just for spacing a group of items that don't need the pill-within-a-pill look: 

Copied!content_copy
<div class="toolbar-track toolbar-track-bare">
  <div class="toolbar-track-indicator"></div>
  <button class="toolbar-track-item is-active">List</button>
  <button class="toolbar-track-item">Grid</button>
</div>

Slider

toolbar-slider wraps a plain range-field in the same pill container as toolbar-track - it's not just cosmetic: the range's native track line is the same color as the toolbar's own background, so without a container to contrast against it's invisible. The container also vertically centers any label text/icons placed next to it.

With custom labels on each side (e.g. a zoom level):

-

+ 
Copied!content_copy
<div class="toolbar-slider">
  <span>-</span>
  <p class="range-field">
    <input type="range" min="70" max="150" value="100">
  </p>
  <span>+</span>
</div>

With icons instead of text, or no label at all:

volume_down

volume_up

Dropdown

A real Dropdown instance, triggered from a button inside a toolbar-group - same dropdown-trigger/dropdown-content markup as everywhere else, auto-initialized like any other dropdown on the page.

sort palette
  • Name
  • Date
  • Priority
  • Department
  • Status

Same M.Dropdown.init()/getInstance() API as on the Dropdown page - nothing toolbar-specific about it.

Expandable Search

Starts as just an icon button and expands into a text input on focus (or once it has a value) - click the icon below. Press Escape to clear and collapse it again. 

Copied!content_copy
<div class="toolbar-search">
  <button class="toolbar-search-toggle"><i class="material-icons">search</i></button>
  <input class="toolbar-search-input" placeholder="Search...">
</div>

Initialization

Auto-initializes on every .toolbar element via Auto Init, or explicitly: 

Copied!content_copyvar elems = document.querySelectorAll('.toolbar');
var instances = M.Toolbar.init(elems, options);

Or with jQuery:

Copied!content_copyvar instance = M.Toolbar.getInstance(elem);

Methods

Method Description
updateIndicators() Re-measures and repositions every track's sliding indicator. Call it after changing which toolbar-track-item is active from your own code (rather than by a user click), or after anything else that could have changed the toolbar's layout/width.
destroy() Removes the instance's event listeners.
