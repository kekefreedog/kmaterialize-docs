Basic example

Choose a number with small or large adjustments. Fine arrows sit next to the value; coarse arrows sit on the outside.

Use the single arrows for one step and the double arrows for ten. You can also type a value directly.

Single arrows: ±1 · Double arrows: ±10 · Range: 0–100

  <div class="input-field col s12">
    <label for="quantity">Quantity</label>

Setup

{{> input-setup-note }}

Install the optional imask peer and load Materialize CSS. The arrow controls and styles are implemented in kmaterialize. Initialize NumberInput once, or use M.AutoInit(). This documentation initializes the examples through its shared page setup.

import { NumberInput } from 'kmaterialize';

const input = document.querySelector<HTMLInputElement>('#quantity')!;
const number = NumberInput.init(input, {
  controls: true,
  step: 1,
  largeStep: 10,
});
await number.ready;
number.increment();      // +1
number.decrement(true);  // -10

input.addEventListener('change', () => {
  console.log(number.mask?.typedValue); // numeric value without separators
});

// When removing the view:
// number.destroy();

For the decimal alternative, use { controls: true, step: 0.1, largeStep: 1 }. Wrap each example in input-field col s12 inside a row, as shown above. Labels stay above the arrow controls; the original field without arrows retains its floating label.

Filled, outlined, or rounded

Choose the same border treatment as your text fields: filled with an underline, or outlined with a full border and 4px corners. Rounded keeps the original 16px corners. Fine arrows have a lighter tint; coarse arrows have a stronger tint. Both follow the environment color and dark mode.

Limits, disabled, and read-only

Reference

Options and methods

Option / attributeDefault and behavior
controls / data-number-controlsOff by default. Add the attribute, or set controls: true, to enable the four arrows. data-number-controls="false" keeps them off.
data-number-variantrounded (default), outlined, or filled. Sets the border appearance; arrow colors inherit from the Material theme.
step / step1. The small increment; must be positive. Options take precedence over attributes.
largeStep / data-number-large-stepTen times step. The large increment; must be positive.
min / min, max / maxNo limit by default. Arrow changes clamp to the bounds.
scaleWith controls, decimal places are inferred from both increments unless explicitly supplied.
thousandsSeparator / radix / mapToRadixSpace / dot / comma. Existing IMask formatting options.
disabled / readonlyNative attributes disable adjustment. Disabled fieldsets are respected too.

increment(large?) and decrement(large?) adjust by one fine or coarse step after ready. Each adjustment emits bubbling input and change events. Use mask.typedValue when your application needs a number rather than formatted text. destroy() removes the controls, mask, and listeners and restores the original accessibility attributes.

Keyboard and accessibility

Focus the number field and use Up/Down for the fine step, or Page Up/Page Down and Shift+Up/Down for the coarse step. Left/Right remain available for moving the text cursor. Each arrow is a native button with its increment in its accessible name; Enter and Space activate it. The input exposes its current value and limits as a spinbutton.

Colors inherit the surrounding Material theme and dark mode. The controls work without icon fonts, and do not require animation.
