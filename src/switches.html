Switches are special checkboxes used for binary states such as on / off

Copied!content_copy<!-- Switch -->
<div class="switch">
  <label>
    Off
    <input type="checkbox">
    <span class="lever"></span>
    On
  </label>
</div>
<!-- Disabled Switch -->
<div class="switch">
  <label>
    Off
    <input type="checkbox" disabled>
    <span class="lever"></span>
    On
  </label>
</div>

Icon inside the thumb

The circle shows a check when enabled and a cross when disabled. Click the switch or focus it and press Space to toggle.

Copied!content_copy<div class="switch switch-with-icon">
  <label>
    Off
    <input type="checkbox" aria-label="Enable notifications" checked>
    <span class="lever" aria-hidden="true"></span>
    On
  </label>
</div>

Add switch-with-icon to a standard Materialize switch and load the Material Icons font. The icon styling is included in kmaterialize. The icons are decorative; the checkbox provides the accessible name and checked state.

Custom Material Icons

Try a notification switch: a muted bell when off and a ringing bell when on. Set --switch-icon-off and --switch-icon-on to quoted Material Icons names to choose your own icons.

Copied!content_copy<div class="switch switch-with-icon"
     style="--switch-icon-off: 'notifications_off'; --switch-icon-on: 'notifications_active';">
  <label>
    Notifications
    <input type="checkbox" aria-label="Enable notifications">
    <span class="lever" aria-hidden="true"></span>
  </label>
</div>

These properties are built into kmaterialize's switch-with-icon variant. Load the Material Icons font; no extra CSS or JavaScript is needed.
