Password field

Use type="password" with the same input wrapper and label as a text field. The browser hides the characters as you type.

<div class="input-field">
    <input id="password" name="password" type="password" class="validate" placeholder=" " maxlength="20" autocomplete="current-password">
    <label for="password">Password</label>
</div>

Show/hide toggle

Add data-password-toggle to the input and data-password-toggle-icon to a suffix button, then initialize PasswordInput. Click the eye or focus the button and press Enter or Space to show or hide the password. Its value and selection stay unchanged.

<div class="input-field">
    <button type="button" class="suffix btn-flat p-0 transparent screen-flex screen-center on-surface-variant-text waves-effect waves-circle" data-password-toggle-icon aria-label="Show password">
        <i class="material-icons" aria-hidden="true">visibility</i>
    </button>
    <input id="password-toggle-example" type="password" class="validate" data-password-toggle placeholder=" ">
    <label for="password-toggle-example">Password</label>
</div>

Initialization

import { PasswordInput } from 'kmaterialize';

const instances = PasswordInput.init(document.querySelectorAll('input[data-password-toggle]'));

Initialization updates the icon, aria-label, aria-pressed, and aria-controls. Disabled inputs cannot be revealed; readonly inputs can. Native buttons support keyboard activation automatically. Existing suffix wrappers remain supported.

Initialize each field once with PasswordInput.init() or M.AutoInit(). These live examples use the shared documentation initializer.

Custom labels and lifecycle

const input = document.querySelector('#password-toggle-example');
const instance = PasswordInput.init(input, {
    showLabel: 'Show password',
    hideLabel: 'Hide password'
});

instance.toggle(); // Show or hide without changing the value.
instance.destroy(); // Remove listeners before removing the field.
