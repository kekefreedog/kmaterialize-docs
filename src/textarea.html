Rich text, native forms

Write formatted text using Quill 2. Headings, emphasis, lists, quotes, and links use a Material toolbar. The original textarea keeps the serialized value for normal form submission.

Required. Try formatting, then submit to inspect the form value. Clear the editor to test validation.

Setup

Quill is an optional peer dependency. Load its Snow stylesheet before Materialize. The editor code loads when an opted-in textarea is initialized.

npm install kmaterialize quill
Copied!content_copyimport 'quill/dist/quill.snow.css';
import 'kmaterialize/dist/css/materialize.css';
import { RichTextarea } from 'kmaterialize';

const field = RichTextarea.init(
  document.querySelector<HTMLTextAreaElement>('#brief')!
);
await field.ready;

console.log(field.getHTML());
console.log(field.getText());

Alternatively, M.AutoInit() enhances textarea[data-editor="quill"]. Add no-autoinit when you want to initialize a field yourself. Await the instance’s ready promise before using field.quill.

Without a bundler, load quill.snow.css, then Materialize CSS, followed by quill.js and materialize.js. The component can use window.Quill.

Compact toolbar and plain-text value

Choose which controls to show. This example preserves formatting in the editor while storing plain text in the native textarea.

const note = RichTextarea.init(textarea, {
  valueFormat: 'text',
  toolbar: [['bold', 'italic'], [{ list: 'bullet' }], ['clean']]
});
await note.ready;

HTML is the default value format. Use valueFormat: 'text' or data-value-format="text" for plain text; formatting is not preserved when that plain-text value is reloaded.

Read-only and disabled

Use the native readonly and disabled attributes. Disabled fields are omitted from form submission. State changes are reflected in the editor and toolbar automatically.

Values, events, and cleanup

Copied!content_copyawait field.ready;
field.setValue('<p>A <strong>formatted</strong> update.</p>');
const html = field.getHTML();
const text = field.getText();
const storedValue = field.getValue();

// Native input fires as content changes; change fires when leaving the editor.
textarea.addEventListener('input', () => console.log(textarea.value));

// After assigning textarea.value directly:
textarea.value = '<p>Loaded from a saved draft.</p>';
field.refresh();

// Access Quill's API and Delta document:
const delta = field.quill!.getContents();

// Restore the native textarea, retaining the latest serialized value:
field.destroy();

The native name, required, and form reset behavior are preserved. An empty editor stores an empty string, so required validation works. HTML is normalized through Quill’s supported formats; it is not stored byte-for-byte.

The default toolbar supports text formatting and links. Customize toolbar and formats, or set toolbar: false for a toolbar-free editor. TypeScript options are exported as RichTextareaOptions.

Set --rich-textarea-min-height and --rich-textarea-max-height on the generated .rich-textarea to adjust the writing area. All component styles are shipped by kmaterialize.
