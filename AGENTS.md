# Project instructions

This repository (`kmaterialize-docs`) is only a presentation and documentation of Kmaterialize features.

- Make all library updates, feature implementations, bug fixes, and reusable component or styling changes in the Kmaterialize project at `../kmaterialize`.
- Read and follow that project's `AGENTS.md` instructions before editing its files.
- Limit changes in this repository to documentation, feature presentations, examples, and the infrastructure needed to display them.
- Examples must use the Kmaterialize implementation. Do not duplicate library behavior or add local fixes here to compensate for library issues; fix those issues in the Kmaterialize project and then update the presentation as needed.
